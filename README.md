# Weather Dashboard

## Description
A responsive weather dashboard that allows users to view weather information using a clean and interactive interface.

## Features
- Search for weather information
- Display current weather details
- Responsive design
- User-friendly interface
- JavaScript-based interactions

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the dashboard to view weather information.
